# Blade Mage: Undercroft

3D cel-shaded anime action RPG in the browser (Three.js + Vite). Play a blade mage in a mage academy; descend three dungeon levels beneath the school.

    npm install
    npm run dev      # or: npm run build && npm run preview

Controls: WASD move · Q/E camera · LMB/J light combo · RMB/K heavy · Space dodge · 1 Flame Edge · 2 Frost Nova · 3 Arc Bolt · F potion · R interact · Tab tactical slow-mo.

Story and names live in `src/data.js` and are placeholders until the real lore is added.
